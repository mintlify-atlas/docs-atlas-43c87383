Fyne is a cross-platform GUI toolkit written in Go, inspired by Material Design. With a single codebase, you can ship native apps to Windows, macOS, Linux, Android, iOS, and WebAssembly — no platform-specific code required.

## Get Up and Running

<Steps>
  <Step title="Install prerequisites">
    Install Go 1.22+, a C compiler, and your system's development tools. See the [Prerequisites](/prerequisites) page for platform-specific instructions.
  </Step>
  <Step title="Add Fyne to your project">
    ```bash
    go get fyne.io/fyne/v2@latest
    go mod tidy
    ```
  </Step>
  <Step title="Write your first app">
    ```go main.go
    package main

    import (
        "fyne.io/fyne/v2/app"
        "fyne.io/fyne/v2/container"
        "fyne.io/fyne/v2/widget"
    )

    func main() {
        a := app.New()
        w := a.NewWindow("Hello")

        hello := widget.NewLabel("Hello Fyne!")
        w.SetContent(container.NewVBox(
            hello,
            widget.NewButton("Hi!", func() {
                hello.SetText("Welcome :)")
            }),
        ))

        w.ShowAndRun()
    }
    ```
  </Step>
  <Step title="Run it">
    ```bash
    go run main.go
    ```
  </Step>
</Steps>
