In this guide you will create a small desktop application that displays a greeting label and a button. When the button is clicked the label text changes — a simple but complete demonstration of Fyne's reactive widget model. The whole thing fits in a single `main.go` file and runs with one command.

<Note>
  Make sure Go 1.22+, a C compiler, and your platform's development headers are installed before continuing. See the [Prerequisites](/prerequisites) page for step-by-step setup instructions for every supported OS.
</Note>

## Steps

<Steps>
  <Step title="Create a Go module">
    Create a new directory for your project and initialise a Go module inside it:

    ```bash
    mkdir myapp && cd myapp
    go mod init myapp
    ```

    The module name (`myapp`) can be any valid Go module path. Use a reverse-DNS style name (e.g. `com.example.myapp`) if you plan to package the app for mobile stores.
  </Step>

  <Step title="Add Fyne as a dependency">
    Download the latest Fyne release and tidy the module graph:

    ```bash
    go get fyne.io/fyne/v2@latest
    go mod tidy
    ```

    <Note>
      As of Go 1.18, `go get` only registers the module in `go.mod` — it does not resolve transitive dependencies. Running `go mod tidy` afterwards pulls in everything Fyne needs and removes any unused entries.
    </Note>
  </Step>

  <Step title="Write the Hello World app">
    Create a file called `main.go` with the following content. Every identifier used here comes directly from the Fyne public API:

    ```go
    package main

    import (
        "fyne.io/fyne/v2/app"
        "fyne.io/fyne/v2/container"
        "fyne.io/fyne/v2/widget"
    )

    func main() {
        a := app.New()
        w := a.NewWindow("Hello")

        hello := widget.NewLabel("Hello Fyne!")
        w.SetContent(container.NewVBox(
            hello,
            widget.NewButton("Hi!", func() {
                hello.SetText("Welcome :)")
            }),
        ))

        w.ShowAndRun()
    }
    ```

    Here is what each part does:

    - `app.New()` — creates a new `fyne.App` backed by the default desktop driver.
    - `a.NewWindow("Hello")` — asks the driver to create a titled OS window and returns a `fyne.Window`.
    - `widget.NewLabel` / `widget.NewButton` — standard widgets from the `widget` package.
    - `container.NewVBox` — arranges its children in a vertical stack.
    - `w.ShowAndRun()` — makes the window visible and starts the Fyne event loop; it blocks until the last window is closed.
  </Step>

  <Step title="Run on desktop">
    From your project directory, run:

    ```bash
    go run main.go
    ```

    A small window will appear with the label and button. Click **Hi!** to see the label update.

    <Note>
      The **first** compilation of Fyne on Windows can take up to 10 minutes depending on your hardware because CGo must compile the underlying OpenGL bindings. Subsequent builds are fast thanks to Go's build cache.
    </Note>
  </Step>

  <Step title="Try the mobile simulator">
    Fyne includes a mobile simulation mode that wraps your app in a phone-shaped chrome so you can preview layout and touch targets without a physical device:

    ```bash
    go run -tags mobile main.go
    ```

    The window will resize to a portrait phone form factor and touch events will be simulated by mouse clicks.
  </Step>
</Steps>

## Explore the widget demo

The official Fyne demo app is the quickest way to see every built-in widget and theme option in action. Install and run it with:

```bash
go install fyne.io/demo@latest
demo
```

The demo showcases buttons, sliders, lists, tables, rich text, dialogs, and much more — all using the same APIs available to your own apps.
