The `theme` package controls the visual appearance of every Fyne widget. A theme is a named set of colors, sizes, fonts, and icons looked up at render time, so a single call to `app.Settings().SetTheme(myTheme)` instantly re-renders the entire UI. The default theme adapts to the operating system's light/dark preference. Custom themes are created by implementing the `fyne.Theme` interface.

```go
import "fyne.io/fyne/v2/theme"
```

---

## `fyne.Theme` Interface

```go
type Theme interface {
    Color(name ThemeColorName, variant ThemeVariant) color.Color
    Font(style TextStyle) Resource
    Icon(name ThemeIconName) Resource
    Size(name ThemeSizeName) float32
}
```

Implement all four methods to create a fully custom theme. For partial customization, embed an existing theme and override only the methods you need.

```go
type myTheme struct{}

var _ fyne.Theme = (*myTheme)(nil)

func (m *myTheme) Color(name fyne.ThemeColorName, variant fyne.ThemeVariant) color.Color {
    if name == theme.ColorNamePrimary {
        return color.NRGBA{R: 0xff, G: 0x60, B: 0x00, A: 0xff}
    }
    return theme.DefaultTheme().Color(name, variant)
}

func (m *myTheme) Font(style fyne.TextStyle) fyne.Resource {
    return theme.DefaultTheme().Font(style)
}

func (m *myTheme) Icon(name fyne.ThemeIconName) fyne.Resource {
    return theme.DefaultTheme().Icon(name)
}

func (m *myTheme) Size(name fyne.ThemeSizeName) float32 {
    return theme.DefaultTheme().Size(name)
}

// Apply:
a.Settings().SetTheme(&myTheme{})
```

## Theme Helper Functions

### `theme.DefaultTheme`

```go
func DefaultTheme() fyne.Theme
```

Returns the built-in adaptive theme that switches between light and dark based on the OS preference.

### `theme.DarkTheme`

```go
func DarkTheme() fyne.Theme
```

Returns a fixed dark variant. **Deprecated** — use a custom theme or `DefaultTheme()` instead; ignores user preference.

### `theme.LightTheme`

```go
func LightTheme() fyne.Theme
```

Returns a fixed light variant. **Deprecated** — same caveat as `DarkTheme()`.

### `theme.Current`

```go
func Current() fyne.Theme
```

Returns the effective theme currently applied to the running application. *(Since 2.5)*

### `theme.CurrentForWidget`

```go
func CurrentForWidget(w fyne.CanvasObject) fyne.Theme
```

Like `Current()` but respects per-widget theme overrides set via a `container.ThemeOverride` container. *(Since 2.5)*

### Color Shorthand Functions *(Deprecated — use `theme.Color(name)` instead)*

```go
func BackgroundColor() color.Color
func ButtonColor() color.Color
func ForegroundColor() color.Color
func PrimaryColor() color.Color
func HoverColor() color.Color
func FocusColor() color.Color
func ErrorColor() color.Color
func SuccessColor() color.Color
func WarningColor() color.Color
func DisabledColor() color.Color
```

These shorthands remain for backward compatibility. In new code use:

```go
theme.Color(theme.ColorNamePrimary)
theme.ColorForWidget(theme.ColorNameForeground, myWidget)
```

## `TextStyle` Struct

```go
type TextStyle struct {
    Bold      bool
    Italic    bool
    Monospace bool
    Symbol    bool
    TabWidth  int
}
```

Used to select the correct font from `fyne.Theme.Font()` and to style `canvas.Text` and widget labels.

```go
boldItalic := fyne.TextStyle{Bold: true, Italic: true}
canvas.NewText("Important", color.Black).TextStyle = boldItalic
```
