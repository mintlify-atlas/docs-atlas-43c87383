Everything visible in a Fyne window is a `CanvasObject` — the single interface that unifies widgets, containers, and raw drawing primitives. The `canvas` package provides the low-level building blocks: solid shapes, images, text, gradients, pixel-by-pixel rasters, and smooth animations. Mastering these primitives gives you complete control over how your application looks and moves.

## The CanvasObject Interface

`fyne.CanvasObject` is the root interface every drawable element must satisfy. It covers geometry, visibility, and refresh:

```go
type CanvasObject interface {
    // Geometry
    MinSize() Size
    Move(Position)
    Position() Position
    Resize(Size)
    Size() Size

    // Visibility
    Hide()
    Visible() bool
    Show()

    // Redraw
    Refresh()
}
```

<Note>
  If an object lives inside a layout-managed `Container`, avoid calling
  `Move()` or `Resize()` directly — the layout algorithm owns those properties.
  Use `Refresh()` when the object's internal state changes and it needs to be
  redrawn.
</Note>

## The Canvas Interface

`fyne.Canvas` is the drawing surface owned by a `Window`. You rarely interact with it directly, but it provides useful utilities:

```go
canvas := w.Canvas()

// Size of the drawing area in density-independent pixels
size := canvas.Size()

// Current device scale factor
scale := canvas.Scale()

// Capture a screenshot of the current canvas state
img := canvas.Capture() // returns image.Image

// Focus management
canvas.Focus(myEntry)
canvas.FocusNext()
canvas.FocusPrevious()
canvas.Unfocus()
focused := canvas.Focused()

// Overlay stack (for popups, dialogs, etc.)
overlays := canvas.Overlays()

// Global keyboard handlers
canvas.SetOnTypedKey(func(ev *fyne.KeyEvent) {
    if ev.Name == fyne.KeyEscape {
        w.Close()
    }
})
```

## Primitive Canvas Objects

All primitives live in the `fyne.io/fyne/v2/canvas` package.

### Rectangle

The most fundamental filled shape. Supports stroke, corner radius, and (since v2.8) a drop shadow.

```go
import "fyne.io/fyne/v2/canvas"

rect := canvas.NewRectangle(color.RGBA{R: 0x42, G: 0x85, B: 0xF4, A: 0xFF})
rect.StrokeColor = color.Black
rect.StrokeWidth = 2
rect.CornerRadius = 8  // rounded corners (since 2.4)

// Per-corner radii override CornerRadius (since 2.7)
rect.TopLeftCornerRadius = 16
rect.TopRightCornerRadius = 16
rect.BottomLeftCornerRadius = 0
rect.BottomRightCornerRadius = 0
```

### Circle

A circle defined by two bounding-box positions.

```go
circle := canvas.NewCircle(color.RGBA{R: 0xFF, G: 0x44, B: 0x44, A: 0xFF})
circle.StrokeColor = color.Black
circle.StrokeWidth = 3
circle.Resize(fyne.NewSize(80, 80))
```

### Line

A line segment between two explicit positions. Lines can have negative width or height to represent an upward slope.

```go
line := canvas.NewLine(color.Gray{Y: 0x80})
line.StrokeWidth = 2
line.Position1 = fyne.NewPos(10, 10)
line.Position2 = fyne.NewPos(200, 100)
```

### Image

Images can be loaded from a file path, an in-memory `fyne.Resource`, or a `image.Image` value. The `FillMode` controls how the image fits its bounds.

```go
// From file
img := canvas.NewImageFromFile("assets/logo.png")

// From a bundled resource (generated by fyne bundle)
img := canvas.NewImageFromResource(resourceLogoPng)

// From an in-memory image.Image
img := canvas.NewImageFromImage(myGoImage)

// Fill modes
img.FillMode = canvas.ImageFillContain  // maintain aspect, letterbox
img.FillMode = canvas.ImageFillStretch  // stretch to fill (default)
img.FillMode = canvas.ImageFillOriginal // keep natural pixel size
img.FillMode = canvas.ImageFillCover    // fill and clip edges (since 2.7)

// Scaling interpolation
img.ScaleMode = canvas.ImageScaleSmooth   // bilinear (default)
img.ScaleMode = canvas.ImageScalePixels   // nearest-neighbour
img.ScaleMode = canvas.ImageScaleFastest  // GPU accelerated

// Translucency: 0.0 = fully opaque, 1.0 = invisible
img.Translucency = 0.3

// Rounded corners (since 2.7)
img.CornerRadius = 12
```

### Text

A plain text primitive with configurable font size, style, color, and alignment.

```go
txt := canvas.NewText("Hello, Fyne!", color.Black)
txt.TextSize = 24
txt.TextStyle = fyne.TextStyle{Bold: true}
txt.Alignment = fyne.TextAlignCenter

// Italic bold
txt.TextStyle = fyne.TextStyle{Bold: true, Italic: true}

// Monospace
txt.TextStyle = fyne.TextStyle{Monospace: true}

// Custom font resource (since 2.5)
txt.FontSource = resourceMyFontTtf
```

<Tip>
  For interactive text labels in widgets use `widget.Label` instead of
  `canvas.Text`. `canvas.Text` is best suited for custom drawing, overlays, and
  graphics where you need precise placement.
</Tip>

### Raster

`canvas.Raster` lets you render pixel-perfect graphics with a `Generator` callback that receives the current canvas width and height in pixels and returns an `image.Image`.

```go
// Using a full-image generator
raster := canvas.NewRaster(func(w, h int) image.Image {
    img := image.NewRGBA(image.Rect(0, 0, w, h))
    for y := 0; y < h; y++ {
        for x := 0; x < w; x++ {
            img.Set(x, y, color.RGBA{
                R: uint8(x * 255 / w),
                G: uint8(y * 255 / h),
                B: 128,
                A: 255,
            })
        }
    }
    return img
})

// Using a per-pixel callback (simpler but slower)
raster := canvas.NewRasterWithPixels(func(x, y, w, h int) color.Color {
    return color.RGBA{R: uint8(x % 256), G: uint8(y % 256), B: 128, A: 255}
})
```

## Animations

The `canvas` package provides three high-level animation constructors, all of which return a `*fyne.Animation` that you `Start()` and `Stop()` explicitly.

### Color Animation

Smoothly interpolates between two `color.Color` values over a duration:

```go
rect := canvas.NewRectangle(color.White)

anim := canvas.NewColorRGBAAnimation(
    color.White,
    color.RGBA{R: 0xFF, G: 0x45, B: 0x00, A: 0xFF},
    canvas.DurationStandard, // 300 ms
    func(c color.Color) {
        rect.FillColor = c
        rect.Refresh()
    },
)
anim.Start()
```

### Size Animation

Interpolates a `fyne.Size` to animate growing or shrinking:

```go
anim := canvas.NewSizeAnimation(
    fyne.NewSize(50, 50),
    fyne.NewSize(200, 200),
    canvas.DurationStandard,
    func(s fyne.Size) {
        myObj.Resize(s)
    },
)
anim.AutoReverse = true
anim.RepeatCount = fyne.AnimationRepeatForever
anim.Start()
```

### Position Animation

Interpolates a `fyne.Position` for sliding effects:

```go
anim := canvas.NewPositionAnimation(
    fyne.NewPos(0, 0),
    fyne.NewPos(300, 0),
    canvas.DurationShort, // 150 ms
    func(p fyne.Position) {
        myObj.Move(p)
    },
)
anim.Start()
```

### Animation Curves and Options

Base animations created with `fyne.NewAnimation` expose additional control:

```go
anim := fyne.NewAnimation(500*time.Millisecond, func(progress float32) {
    // progress goes from 0.0 to 1.0
    rect.FillColor = interpolateColor(progress)
    rect.Refresh()
})
anim.Curve       = fyne.AnimationEaseInOut // default
anim.AutoReverse = true
anim.RepeatCount = fyne.AnimationRepeatForever // loop forever
anim.Start()
// Later:
anim.Stop()
```

Available curves: `fyne.AnimationEaseInOut`, `fyne.AnimationEaseIn`, `fyne.AnimationEaseOut`, `fyne.AnimationLinear`.

## Complete Drawing Example

```go
package main

import (
    "image/color"
    "time"

    "fyne.io/fyne/v2"
    "fyne.io/fyne/v2/app"
    "fyne.io/fyne/v2/canvas"
    "fyne.io/fyne/v2/container"
)

func main() {
    a := app.New()
    w := a.NewWindow("Canvas Primitives")

    bg := canvas.NewVerticalGradient(
        color.RGBA{R: 0x1A, G: 0x1A, B: 0x2E, A: 0xFF},
        color.RGBA{R: 0x16, G: 0x21, B: 0x3E, A: 0xFF},
    )

    circle := canvas.NewCircle(color.RGBA{R: 0xE9, G: 0x4F, B: 0x37, A: 0xFF})
    circle.StrokeColor = color.White
    circle.StrokeWidth = 3

    label := canvas.NewText("Fyne Canvas", color.White)
    label.TextSize = 28
    label.TextStyle = fyne.TextStyle{Bold: true}
    label.Alignment = fyne.TextAlignCenter

    // Animate the circle colour
    anim := canvas.NewColorRGBAAnimation(
        color.RGBA{R: 0xE9, G: 0x4F, B: 0x37, A: 0xFF},
        color.RGBA{R: 0x53, G: 0xD8, B: 0xFB, A: 0xFF},
        time.Second,
        func(c color.Color) { circle.FillColor = c; circle.Refresh() },
    )
    anim.AutoReverse = true
    anim.RepeatCount = fyne.AnimationRepeatForever
    anim.Start()

    w.SetContent(container.NewStack(bg, container.NewVBox(circle, label)))
    w.Resize(fyne.NewSize(400, 300))
    w.ShowAndRun()
}
```
